## What

When you save something a small indicator "Gespeichert" next to that section is shown in the admin ui.
However, if you're editing a page with a lot of content and you press the save button at the bottom, you see no indicator (because it's way too far up).
I would prefer:
1. if the save button is always in view
2. when you save, a always visible notification is shown that it succeeded
